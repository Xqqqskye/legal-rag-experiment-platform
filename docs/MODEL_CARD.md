# Model Card: LegalRAG Lab

## 当前状态

- 在线 Demo 使用供应商 API 模型，模型标识由 `.env` 和前端实验配置决定。
- 本仓库没有加载、托管或发布项目自行微调的模型。
- `training/` 中的 QLoRA 文件是待执行的实验配置，不是训练完成证明。
- 仓库不包含 Adapter、checkpoint、真实训练日志或经过专家确认的微调增益。

## 预期用途

- 中文法律 RAG 的检索、重排、引用与 Prompt 对照实验；
- 比较不同模型、检索策略在质量、延迟和成本上的权衡；
- 批量评测、Bad Case 归因与产品原型展示。

## 不适用范围

- 替代执业律师给出个案法律意见；
- 在没有证据的情况下断言罪名、责任比例、赔偿金额或程序期限；
- 自动作出司法、行政或执法决定；
- 处理未经授权的个人敏感信息或秘密数据。

## 微调模型的上线门槛

计划中的 QLoRA 模型只有满足以下条件，才可以在 README 中标记为“已训练”：

1. 保存真实训练日志、配置哈希、代码版本和数据版本；
2. 使用与训练集隔离的测试集，对比 API 基线与未微调基座；
3. 报告引用 Precision、Evidence Faithfulness、法律适用性、专家通过率、延迟和成本；
4. 对过期法源、关系边界、刑民交叉、程序时效等高风险 Bad Case 做专家抽检；
5. 明确训练数据来源、许可证、个人信息处理方式和已知限制。
